# New Talents

Base ejecutable multiplataforma de New Talents. La Feature 001 mantiene tres límites independientes:

- frontend Expo para web, Android e iOS;
- backend HTTP NestJS ejecutado directamente en el host;
- PostgreSQL local aislado, administrado exclusivamente por Docker Compose.

La preparación, configuración, ejecución y verificación local están documentadas en
[`docs/desarrollo/entorno-local.md`](docs/desarrollo/entorno-local.md).

Esta base no contiene funcionalidades de producto, autenticación ni modelos de negocio.
