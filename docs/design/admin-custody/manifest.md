## Interaction reference

- Registration requests use a stage-based operational queue with a focused next action; the complete list remains available as a secondary destination instead of dominating the module.
- Desktop custody uses drag and drop only to select a target Analyst; the open confirmation surface shows that no assignment is saved until **Confirmar asignación** is activated.
- Mobile custody uses the accessible **Asignar** action and the same confirmation boundary instead of requiring dragging.
- Passport detail exposes **Asignar Analista**, **Cambiar Analista**, and **Retirar custodia** according to the current custody state.
- Dossiers, registration requests, and passports remain visually and conceptually distinct.
